# Dashboard

**Mahmoud** is a modern, fully responsive multi-page dashboard designed for personal portfolios, freelancers, and individuals. It features a clean, professional layout with separate pages for Dashboard, Settings, Profile, Projects, Courses, Friends, Files, and Plans.

## Features

- Fully responsive design (mobile, tablet, desktop)
- Clean and minimal UI/UX
- Easy navigation with a collapsible menu
- Multi-page structure with dedicated pages for Dashboard, Settings, Profile, Projects, Courses, Friends, Files, and Plans
- Customizable content and styles
- Optimized for performance

## Pages

- **Dashboard** (`index.html`): Main overview page with various sections like articles, gallery, features, testimonials, etc.
- **Settings** (`settings.html`): User settings and configuration
- **Profile** (`profile.html`): User profile information
- **Projects** (`projects.html`): Project listings and management
- **Courses** (`courses.html`): Course-related content
- **Friends** (`friends.html`): Friends or contacts list
- **Plans** (`plans.html`): Plans, subscriptions, or pricing details
- **Files** (`files.html`): File management and uploads

## Technologies Used

- HTML5
- CSS3 (with Font Awesome icons)
- Google Fonts (Open Sans)

## Installation and Usage

1. Clone or download this repository to your local machine.
2. Open any of the HTML files (e.g., `index.html` for the main dashboard) in any modern web browser to view the template.
3. Customize the content in the HTML files and styles in `css/style.css` as needed.
4. For deployment, upload the files to your web server.
